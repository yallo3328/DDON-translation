DDON 한국어 패치 1.0
=====================

드래곤즈 도그마 온라인(DDON) 리바이벌 서버(live.ddon.org) 클라이언트용
비공식 한국어 패치입니다. 게임 안의 문장(퀘스트, NPC 대사, 이벤트, 폰 대사,
아이템, 스킬, 업적, UI)과 일부 메뉴 그림 글자를 한국어로 바꿉니다.

설치
1. 게임과 런처를 모두 종료합니다.
2. Install_Korean_Patch.bat 을 실행합니다.
3. Dragon's Dogma Online 폴더 경로를 입력합니다.
   예: C:\Games\Dragon's Dogma Online
4. 설치가 끝나면 게임을 실행합니다.

이전 버전에서 업데이트
- 이전 시험판(r11 이후)이 설치된 상태에서 복원하지 않고 같은 방법으로 바로 설치할 수 있습니다.
- 설치기는 이전 설치 기록과 원본 백업을 먼저 검증한 뒤 파일을 교체합니다.
- 기록이나 백업이 손상되었으면 안전을 위해 설치를 중단합니다.

복원(원래 일본어/영어로 되돌리기)
1. 게임과 런처를 모두 종료합니다.
2. Restore_Original.bat 을 실행합니다.
3. 설치할 때 사용한 같은 게임 폴더를 입력합니다.

안전 장치
- 설치 전 모든 대상 파일의 SHA-256을 확인합니다.
- 원본은 게임 폴더의 .ddon-korean-patch\backup 아래에 백업합니다.
- 대상 파일이 예상한 원본과 다르면 설치를 중단합니다.
- 설치 도중 실패하면 이미 교체한 파일을 백업본으로 되돌립니다.

게임 업데이트 후
- 서버/클라이언트 업데이트로 게임 파일이 바뀌면 설치기가 해시 불일치로 설치를 멈춥니다.
  이 경우 새 클라이언트 기준으로 패치를 다시 빌드해야 합니다.

번역 범위
- 메인·월드·개인 퀘스트의 제목, 목표, 설명, 대사
- NPC 일상 대화, 이벤트 장면, 튜토리얼, 도감
- 폰 대사(성격별 말투 유지), 폰 지역 잡담(영어판에도 없던 대사 포함)
- 아이템 이름·설명, 스킬·어빌리티 이름·설명, 업적, 지명, 적 이름
- UI·시스템 메시지, 일부 메뉴 그림 글자(메뉴 머리말, 습득 시련, 승격 시험 등)

알려진 제한
- 채팅 한국어 입력은 지원하지 않습니다(다른 플레이어가 읽을 수 없습니다).
- 서버에서 보내는 일부 메시지는 영어로 표시될 수 있습니다.
- 원래 영어로 디자인된 그림 글자(LEVEL UP, CLEAR 등)는 그대로 둡니다.
- 영어판에서 이름을 붙인 일부 장비명은 영어 발음 표기를 따릅니다.

주요 용어
- 覚者 각성자 / ポーン 폰 / 竜力 용력 / 礎 초석 / リム転移 림 텔레포트
- 속성: 베기·타격·사격 / 화염·얼음·번개·성·어둠
- エリアマスター 지역 마스터 / ジョブ 직업 / 戦技 전투 기술 / 戦徒 전우

문제 신고
- 어색한 문장이나 깨진 글자는 화면 스크린샷과 함께
  어느 메뉴·퀘스트·NPC에서 나왔는지 알려 주세요.
- 저장소: https://github.com/yallo3328/DDON-translation

감사
- 영어 커뮤니티 번역(DDON-translation)과 Arrowgene DDON 서버 프로젝트의
  파일 형식 연구를 바탕으로 만들었습니다.
- 이 패치는 비공식 팬 번역이며 CAPCOM과 관련이 없습니다.
